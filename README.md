# Mi App de Estudio

App web para estudiantes universitarios que integra inteligencia artificial como tutor de estudio.

## Tecnologías

- HTML, CSS, JavaScript
- Supabase (base de datos y autenticación)
- API de Claude (IA)
- Vercel (despliegue)

## Estado actual

- Página principal con formulario de notas
- Conexión con Supabase funcionando
- Autenticación con email/contraseña
- Desplegada en Vercel
